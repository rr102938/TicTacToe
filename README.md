# Tic-Tac-Toe Minimax AI (CS50 AI)

## What it does
* This is a Python program that implements an unbeatable AI opponent for the game of Tic-Tac-Toe using the Minimax algorithm.
* It features a graphical user interface (GUI) built with Pygame where human players can choose to play as X or O against a smart computer agent that mathematically evaluates optimal moves.

## Technologies Used
* Python
* Pygame (Graphical User Interface and event handling)
* Minimax adversarial search algorithm
* Git / GitHub

## How to Run It
* Make sure you have Pygame installed on your computer by running this in your terminal:
* "```bash"
* pip install pygame
* Ensure your tictactoe.py logic file and asset font files are in the same directory.
* Run the main runner script: python runner.py
* Choose whether to play as X or O, and try your best to beat (or tie) the AI.
